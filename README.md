# Prism Intelligence

An AI-powered financial intelligence prototype combining fundamental analysis, technical indicators, alternative data signals, quantitative scoring, and LLM-based natural-language explanations.

> **Note:** This is a demonstration prototype. The included financial, price, and alternative datasets are synthetic and do not represent actual market information.

## 1. Problem Statement

Financial analysis often requires examining multiple sources of information, including company financials, stock price movements, and alternative business signals.

Prism Intelligence combines these inputs into a unified company-level intelligence score and allows users to explore the results through natural-language questions.

## 3. Analysis Components

### Fundamental Analysis

Evaluates:
- Revenue growth
- Net profit growth
- Operating margin
- Earnings per share

Growth rates are calculated quarter-over-quarter using the available financial data.

### Technical Analysis

Calculates:
- Simple Moving Average (SMA 20 and SMA 50)
- Relative Strength Index (RSI 14)
- Moving Average Convergence Divergence (MACD)
- Technical trend classification

### Alternative Data Analysis

Evaluates synthetic signals:
- App downloads
- Web traffic
- Job postings

Growth in these indicators is used to estimate changes in customer interest and hiring activity.

## 4. Quantitative Scoring

The composite intelligence score combines three components:

| Component | Weight |
|---|---:|
| Fundamental | 35% |
| Technical | 35% |
| Alternative | 30% |

Each component is calculated independently and combined using a weighted average.

Individual metrics are converted into scores between 0 and 100 using heuristic scoring functions.

The confidence label represents data availability:
- HIGH: All three components available.
- MEDIUM: Two components available.
- LOW: One component available.

It does not represent statistical confidence or predictive accuracy.

## 5. LLM Integration

The LLM receives structured analysis generated by the Python quantitative engine.

Its responsibilities are to:
- Answer natural-language questions.
- Explain the intelligence score.
- Summarize positive and negative factors.
- Identify risks and data limitations.

Python performs all quantitative calculations. The LLM is responsible for interpretation and explanation.

The system prompt instructs the model to use only the supplied analysis context and avoid inventing financial metrics.

## 6. API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Application health check |
| GET | `/analyze/{symbol}` | Quantitative company analysis |
| POST | `/ask` | Natural-language financial analysis |

Example request:

```json
{
  "symbol": "ZOMATO",
  "question": "Why is the intelligence score positive?"
}
```

## 9. Installation

Clone the repository and enter the project directory.

```bash
python -m venv .venv
```

Activate the environment:

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure environment variables in `.env`:

```env
OPENAI_API_KEY=your_api_key
OPENAI_MODEL=gpt-4.1-mini
```

Run the application:

```bash
uvicorn app.main:app --reload
```

Open API documentation:

`http://127.0.0.1:8000/docs`

Run tests:

```bash
python -m pytest -v
```

## 10. Assumptions and Limitations

- All included datasets are synthetic demonstration data.
- The scoring methodology uses heuristic weights and thresholds.
- The scoring system has not been statistically validated against historical investment outcomes.
- The prototype does not include valuation models, competitor comparisons, macroeconomic analysis, or news sentiment.
- Alternative data signals are simplified and do not establish actual business performance.
- The LLM may produce inaccurate interpretations despite prompt constraints and output validation.
- The prototype does not generate validated trading signals or guarantee investment outcomes.
